# Auto Unsub

A Flutter application for managing and automating subscription management on iOS devices.

## Features

- Google Sign-In integration
- WebView-based banking integration
- Step-by-step guidance for subscription management
- AI-powered subscription analysis
- Secure credential management

## Getting Started

### Prerequisites

- Flutter SDK (latest stable version)
- Xcode 14.0 or later
- iOS 12.0 or later
- CocoaPods

### Installation

1. Clone the repository
```bash
git clone https://github.com/yourusername/auto_unsub.git
```

2. Install dependencies
```bash
flutter pub get
```

3. Install iOS dependencies
```bash
cd ios
pod install
cd ..
```

4. Run the app
```bash
flutter run
```

## Development

This project is focused on iOS development. The app uses:
- WebView for banking integration
- Google Sign-In for authentication
- Provider for state management
- Flutter Overlay Loader for user guidance
